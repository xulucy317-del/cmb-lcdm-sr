# Archived paper draft (superseded)

`main.tex` / `main.pdf` — a two-column LaTeX draft of 2026-08-14, compiled
from `docs/results_compendium.md` at the end of stage 1. It is kept for the
record only:

* **Superseded** by [`report_conclusive.md`](../../../report_conclusive.md),
  the write-up of record, which covers all four stages of the project.
* **Contains a retracted claim.** The draft presents the decoder-side ratio
  `r_dec = −1.87` as a fourth independent readout of the −2 exponent. That
  reading was withdrawn (see `docs/method.md` §4 and `report_conclusive.md`
  §2.5): the (τ, ln A_s) spectral templates are near-collinear, so the
  decoder gives no identifiable readout.
* Its author block is a placeholder, and it predates the linear-baseline
  audit (stage 2) that re-scoped the stage-1 statements.

The live paper source is maintained in a separate Overleaf project.

Build (plain `article`, no bibtex): `pdflatex main && pdflatex main`, run in
this directory. Figures are read from the repository's `figures/` and
`experiments/` directories via `\graphicspath`; the three it uses are
`amplitude_scatter.pdf`, `decoder_amplitude.pdf` (both regenerated by
`figures/make_fig_amplitude.py` and `figures/make_fig_decoder.py`) and
`experiments/knee_readout_lcdm_tt_ee_lowl_envelopes.png`.
